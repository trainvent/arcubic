## Install

- **Web (React):** `npm install --save-exact @trainvent/arcubic@{version}`, import `@trainvent/arcubic/styles.css` once, then import `Theme` and the components from `@trainvent/arcubic`. `trainvent-arcubic-{version}.tgz` is the same package as a download.
- **Obsidian:** install Arcubic from *Settings → Appearance → Themes*, or extract `arcubic-obsidian-{version}.zip` into `<vault>/.obsidian/themes/`. The separate `theme.css` and `manifest.json` files are for Obsidian's automatic installer. Minimum Obsidian version: 1.8.0.
- **VS Code:** install Arcubic from the VS Code Marketplace or Open VSX, or use `arcubic-vscode-{version}.vsix`. `arcubic-vscode.css` adds raised buttons and the triangle loader.
- **Terminal:** `arcubic-dark.Xresources`.

Arcubic is an alpha release. Its code is MIT licensed; bundled fonts keep their OFL licenses. GitHub shows SHA-256 hashes for every download.
