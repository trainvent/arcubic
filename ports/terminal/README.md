# Arcubic Dark terminal palette

`arcubic-dark.Xresources` is generated with `npm run build:terminal` from the shared three-family palette. Import its entries into a terminal that supports Xresources, or use the web preview's Download theme action. No plugin or font bundle is required by this color-only export.

The background and foreground use neutral grays. Teal supplies cyan and the cursor; Amber supplies yellow; Burnt orange supplies bright red. Green and normal red remain semantic status colors. Blue and Purple remain ANSI utility colors, so existing terminal applications retain their color distinctions.

All foreground slots except utility black are checked for at least 4.5:1 contrast against the terminal background. The web preview includes a full ANSI matrix for inspection.
